Death Arena
-----------------------------------------------
장르 : 3인칭 액션

주제 : 엘든링의 보스전 컨텐츠와 비슷한 1:1 전투 게임

개요 :
 - 몬스터와 전투하여 승리(HP를 모두 깎으면 승리)
 - 승리 시 다음 스테이지로 이동
 - 3개의 스테이지, 3 종류의 몬스터 등장
 - 기본 공격과 4 종류의 플레이어 스킬
 - 막기와 대시 가능
 - 막기 성공시 카운터 공격 수행

-----------------------------------------------
조작법

이동 : w, s, a, d

공격
  - 마우스 좌클릭: 기본 공격(최대 2회 콤보 가능)
  - 마우스 우클릭: 막기
  - 1, 2, 3, 4 숫자 키: 스킬 1, 2, 3, 4 수행
